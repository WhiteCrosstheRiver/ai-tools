# ZCode 本机 Token 与套餐额度监控器

Windows 桌面 GUI，展示 ZCode 当前 Windows 用户本机数据库中的模型 Token 记录，并为官方套餐扣减预留独立字段。默认数据库：`%USERPROFILE%\\.zcode\\cli\\db\\db.sqlite`。

## 启动

双击 `启动额度监控器.bat` 可无控制台启动，或运行 `pythonw dashboard.py`。窗口可以最小化并继续监控，关闭窗口即停止。程序每 3 秒检查数据库和 WAL 的变化，有变化时才查询。界面为浅色页面，含活动日历、每日趋势图和模型用量分布图，图表仅使用本机数据库记录。

## 本机 Token

首页默认显示今日的本机 Token，可切换最近 7 天或全部历史；页面同时标明数据库最早和最近一次模型请求时间。活动日历显示最近约一年，趋势图可切换近 7 天/近 30 天，模型分布图显示全部历史。这些历史图表会标明范围，且遵循当前选定来源。明细表和顶部数字遵循统计范围与来源筛选。日期按 Windows 本地时区计算；跨午夜时会自动刷新日期范围。官方周期起止明确可用时，另显示该周期内的本机 Token，按请求开始时间和 `[开始, 结束)` 计算。

## 官方套餐扣减

官方扣减值、单位、范围、统计区间、下次重置、官方数据时间、本地 Token 的官方周期对照分别展示。字段缺失显示“未获取”，明确的零值显示 `0`。若已知重置时间已过，而官方快照仍早于重置时间，会标记“等待官方更新”，保留旧快照并注明其时间。程序不按 Token 数乘固定费率，不从重置时间推算周期开始，也不推测免费、折扣、退款或重置。

当前 ZCode 本地套餐缓存只有套餐连接可用状态，没有官方扣减积分或周期时间，因此本版本会显示“未获取”。本机请求记录和套餐结算可能有不同统计范围、单位和入账时间；ZCode 的闲时任务文档也说明此类任务会产生模型请求，但自动执行请求走专用通道、不消耗套餐额度。官方扣减值只有在发现可靠的本地官方结算数据源后才会显示。

## 隐私与边界

只读 SQLite `model_usage` 表；设置单独保存在 `%LOCALAPPDATA%\\ZCodeTokenMonitor\\settings.json`。不读会话正文或凭据，不发起网络请求，不调用模型，不修改 ZCode 文件。可选择本机磁盘上的数据库；网络共享路径会被拒绝。本机记录不代表其他设备或账号全局消耗，也不等于套餐剩余额度。
